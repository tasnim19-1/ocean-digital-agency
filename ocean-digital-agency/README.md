# Ocean Digital Agency

## فكرة المشروع
مشروعي عبارة عن موقع لوكالة خدمات رقمية باسم Ocean Digital، والهدف منه التعريف بالوكالة والخدمات اللي بتقدمها، وعرض بعض الأعمال، وتوفير طريقة للزوار حتى يتواصلوا معنا.

## أقسام الموقع
- الصفحة الرئيسية.
- قسم من نحن.
- قسم الخدمات.
- معرض الأعمال.
- قسم التواصل.
- تذييل الصفحة.

## التقنيات المستخدمة
- HTML لبناء صفحات وأقسام الموقع.
- CSS لتنسيق الموقع وإضافة الألوان والتصميم.
- JavaScript لإضافة التفاعل والتحقق من بيانات نموذج التواصل.
- Bootstrap للمساعدة في تصميم الموقع وجعله متجاوبًا مع أحجام الشاشات المختلفة.

## طريقة تشغيل الموقع
1. فتح مجلد المشروع.
2. فتح ملف `index.html` باستخدام المتصفح.
3. التنقل بين أقسام الموقع وتجربة نموذج التواصل.

## ملاحظة
تم تقسيم المشروع إلى ملفات منفصلة حتى يكون الكود مرتبًا وأسهل في التعديل.
